just_cache

Moves cold, rarely used files off a fast disk onto slower ones, and leaves a symlink behind so every existing path keeps working.

Point it at a directory and one or more cold-storage roots. On each sweep it walks the tree, asks the filesystem when each file was last used, and moves the files that have gone untouched onto the cold tier, replacing them with a symlink to the new location. 

just_cache \
  --watch /mnt/cache/media \
  --dest /mnt/disk-slow/media \
  --dest /mnt/disk-archive/media \
  --min-idle-days 60 \
  --limit 25

Documentation lives in readme.md and the design rationale in design.md.
